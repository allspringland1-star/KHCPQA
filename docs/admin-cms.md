# Admin CMS

관리자 페이지는 비개발자가 콘텐츠와 자격 데이터를 운영할 수 있도록 단순하고 명확해야 한다.

## 관리자 메뉴

- 대시보드
- 과정 관리자
- 협회 디렉터 관리자
- 커뮤니티 관리자
- 문의 관리자
- 사용자 관리자
- 자격/수료증 데이터 관리자
- 팝업/배너 관리자
- 하단 정보 관리자
- 번역 상태 관리자

## 고객 인수 체크리스트

관리자 화면을 고객에게 넘기기 전에는 대시보드의 `고객 인수 체크리스트` 순서로 최종 점검한다.

1. 교육과정: 한국어 제목, 목록 요약, 과정 개요를 채우고 공개 상태와 공개 URL을 확인한다.
2. 협회 디렉터: 프로필 이미지, 직책, 소개 문구가 실제 공개 페이지와 맞는지 확인한다.
3. 문의 응대: 신규 문의의 처리 상태와 담당자 메모를 남기는 운영 방식을 설명한다.
4. 팝업·하단 정보: 홈 팝업 노출 기간, 연락처, 사업자 정보, 약관 링크를 확인한다.

공개 전환은 `super_admin` 권한으로 처리한다. 과정은 공개 저장 전에 목록 요약과 과정 개요가 필요하며, 다국어 번역본은 자동 공개하지 않는다.

## 권한

| 역할 | 권한 |
| --- | --- |
| Super Admin | 전체 관리 |
| Content Manager | 페이지, 게시글, 갤러리 관리 |

| Certification Manager | 자격 데이터 관리 |

## 콘텐츠 상태

- draft
- translated
- reviewed
- published
- archived

## 4개 언어 번역 운영

- 지원 언어는 한국어(`ko`), 영어(`en`), 스페인어(`es`), 중국 간체(`zh-CN`)다.
- 한국어를 기준 원문으로 사용하고 `/admin/translations`에서 페이지·과정·커뮤니티 번역을 한 대기열로 관리한다.
- 번역본은 `draft → translated → reviewed → published` 순서로 진행하며 최종 `published` 전환은 `super_admin`만 할 수 있다.
- 원문 수정일이 번역 기준일보다 최신이면 `재검수 필요`로 표시한다. 기존 공개본은 자동으로 내리지 않으며 운영자가 검토 후 상태를 변경한다.
- 법무·자격·건강 관련 콘텐츠는 검수자와 검수일이 없으면 공개할 수 없다.
- AI 자동 번역은 1차 범위가 아니다. 후속 기능을 추가하더라도 결과는 항상 `draft`로 저장하고 자동 공개하지 않는다.

## 페이지 관리자 입력 규칙

페이지 관리 탭은 `admin_content_items`의 `Page` 타입을 사용한다.

- `home`, `about`, `curriculum`, `activities`, `contact`: 공개 페이지 상단 제목/요약을 교체한다.
- `privacy`: 개인정보처리방침의 최종 공개 원문을 교체한다.
- `terms`: 이용약관의 최종 공개 원문을 교체한다.

법무 페이지 본문은 빈 줄로 문단을 구분해 입력한다. 최종 법무 검수 전에는 `draft` 또는 `reviewed` 상태로 두고, 공개 승인 후에만 `published`로 변경한다.

## 과정 관리자 입력 규칙

과정 관리 탭은 `admin_content_items`의 `Course` 타입을 사용한다.

- 새 과정은 초기 게시 상태를 선택해 생성할 수 있다. 공개로 생성하려면 제목, 목록 요약, 과정 개요를 함께 입력한다.
- 운영자는 편집 화면의 공개 안내 패널에서 현재 언어의 공개 여부와 공개 URL을 확인한다.
- `main`: 과정 목록 카드와 상세 상단 제목/요약/본문을 교체한다.
- `flow-1`~`flow-4`: 상세 페이지 커리큘럼 흐름 카드에 노출한다.
- `panel-goal`, `panel-strength`, `panel-audience`: 상세 페이지 핵심 안내 패널에 노출한다.
- `technique-1`: 상세 페이지 기술 키워드 영역에 노출한다.
- `process-1`: 상세 페이지 실습 프로세스 영역에 노출한다.

본문은 줄바꿈 목록으로 입력하면 공개 상세 페이지에서 항목형 콘텐츠로 사용된다.

## 관리자 화면 요구사항

- 목록, 검색, 필터, 정렬 제공
- 언어별 콘텐츠 입력 필드 제공
- 게시 상태 변경 제공
- 대표 이미지 업로드와 미리보기 제공
- 대표 이미지 URL 입력 제공
- 원본 URL 저장 필드 제공
- 최근 수정자와 수정일 표시
- 삭제보다 비공개/보관 처리 우선

현재 구현 기준:
- Supabase 환경변수가 설정된 운영/검수 환경에서는 DB 조회 결과가 0건이면 빈 상태를 표시한다.
- Supabase 환경변수가 없는 로컬 프리뷰에서만 정적 데모 행을 사용한다.
- 저장/삭제 액션은 Supabase 환경변수가 없으면 성공으로 처리하지 않고 설정 오류를 표시한다.
- 콘텐츠와 배너는 `image_url`을 저장할 수 있으며, 공개 과정/활동 화면은 published CMS 이미지 URL을 우선 사용한다.
- 개인정보처리방침과 이용약관은 published `Page/privacy`, `Page/terms` 상세 본문이 있으면 placeholder 대신 실제 원문을 표시한다.
- 자격 데이터 관리자는 자격증 다운로드용 배경 디자인을 업로드하고, 성명/자격명/자격번호/발급일/상태/검증코드의 위치와 글자 크기, 색상, 정렬을 조정할 수 있다.
- 자격증 배경 이미지는 개인별 텍스트가 없는 공통 디자인으로 관리하며, 회원별 정보는 DB 자격 데이터에서 합성한다.

## 문의 관리

문의 유형:
- `general`
- `course`
- `certification`
- `partnership`

필드:
- 이름
- 기관명
- 국가
- 이메일
- 연락처
- 관심 분야
- 메시지
- 개인정보 동의 여부
- 처리 상태: `new`, `in_review`, `answered`, `closed`
- 담당자 메모

문자/카카오/이메일 자동 발송은 1차 범위가 아니다.

## 자격 데이터 관리

필드:
- 사용자
- 과정
- 자격증 번호
- 발급일
- 상태: `issued`, `expired`, `revoked`
- 검증 코드
- 관리자 메모

주의:
- 실제 자격 데이터의 정확성은 발주사 책임이다.
- 공개 검증 기능은 별도 확정 전까지 기본 범위로 보지 않는다.
- 증명서 자동 발급은 제외 범위다.

## 관리자 보안

- 관리자 라우트는 인증 필수
- 권한별 접근 제한
- 공개 가입 사용자는 기본 `user` 권한으로 생성하며 관리자 권한은 별도 부여
- 비밀번호 정책 적용
- 관리자 페이지 `noindex`
- 자격 데이터 다운로드 기능은 별도 승인 후 구현
